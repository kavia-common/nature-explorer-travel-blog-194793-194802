# Free Mans Journey (frontend)

React (CRA) frontend for a nature-inspired travel blogging experience.

## Environment variables

This app reads:

- REACT_APP_API_BASE (preferred)
- REACT_APP_BACKEND_URL (fallback)

If no API base is configured or the backend is unavailable, the UI falls back to mock posts for browsing.

## Scripts

- `npm start`
- `npm run build`
- `npm test`
